# Complete ML Bootcamp Roadmap

Personal plan for completing the **Complete A.I. & Machine Learning, Data Science Bootcamp** course (Zero To Mastery, Udemy) from September 19 to December 31, 2026.

## About the Project

The goal is to complete the course in ~15 weeks at a pace of around 8 hours per week, and not just watch the videos, but leave a tangible result in the repository every week: a notebook, a cheat sheet, or a completed project. The priority is building a foundation for AI Engineering: NumPy, Pandas, scikit-learn, and model evaluation. The Deep Learning section is covered mainly for the key concepts (overfitting, transfer learning).

## How the Plan Is Structured

The work is divided into 5 milestones, with one issue per week within each milestone, including a checklist and an expected outcome.

| Milestone              | Deadline | Content                                                      |
| ---------------------- | -------- | ------------------------------------------------------------ |
| M1: Foundations        | Oct 11   | Environment setup, NumPy, Matplotlib, Pandas                 |
| M2: scikit-learn       | Oct 25   | Workflow, metrics, cross-validation, tuning                  |
| M3: Classical ML       | Nov 22   | Heart Disease and Bulldozers projects, buffer week           |
| M4: Deep Learning      | Dec 20   | Neural networks, CNNs, transfer learning, Dog Vision project |
| M5: Finish & Portfolio | Dec 31   | Buffer, storytelling and career, retrospective               |

**Milestones:** By November 1 — NumPy, Pandas, scikit-learn, and the first milestone project completed; by November 22 — all Classical ML content completed; by December 20 — the entire course content completed.

## How to Use the Board

* **Board** — current week: move the issue between columns as the work progresses.
* **Table** — all issues with milestones and labels.
* **Roadmap** — an overall timeline view by date.
* Labels: `setup`, `numpy-pandas`, `sklearn`, `project`, `deep-learning`, `buffer`, `portfolio`, `retro`.

## Rules

1. I reproduce the code by hand and modify it rather than simply watching. I attempt the milestone projects myself first.
2. Every week ends with an artifact committed to the repository.
3. If I fall behind by more than one week by November 22, I will go through the Deep Learning section in “watch and understand the ideas” mode.
